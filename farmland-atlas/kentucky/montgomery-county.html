Sources and terms

Rent ranks count every county with a published rent in the same survey year, within the state (the same counties as the state rent page); other ranks count counties with 10,000 acres or more in farms. This product uses the NASS API but is not endorsed or certified by NASS. Averages, trends, ranks and estimates are calculations by AGSIST.
