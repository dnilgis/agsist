How this page works. Everything above is checked live, in your browser, when the page loads — there is no stored status that could itself go stale. Each feed publishes a timestamp; this page reads it and compares it to how often that feed is supposed to update. “Delayed” and “Idle” account for normal rhythms — grain prices don’t move when the board is closed, and there’s no weekday briefing on a Sunday, so the page won’t cry wolf about either.

What it can and can’t see. If this page loaded at all, the AGSIST website is online. What it checks is whether the data behind each tool is current. It cannot see GitHub’s build system directly — so when several feeds go “Delayed” together, it usually means an upstream provider (often GitHub, which builds and publishes the site) is catching up, not that anything is broken. For GitHub’s own status, see githubstatus.com.
