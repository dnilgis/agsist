<p>This service emits data from the ISU Soil Moisture Network.</p>
<div class="section" id="changelog">
<h1>Changelog</h1>
<ul class="simple">
<li>2026-07-17: The return units of <cite>cci</cite> and <cite>cci_shade</cite> where updated to be
in degF.</li>
<li>2026-03-06: Added comprehensive climate index (CCI) as a download option.
Either <cite>cci</cite> which does not include a shade effect or <cite>cci_shade</cite> which
does.</li>
<li>2025-01-27: Added support for <cite>qcflags</cite> for the inclusion of the flag
values.</li>
<li><strong>2024-11-19</strong> Initial update to use pydantic request validation.</li>
</ul>
</div>
<div class="section" id="example-requests">
<h1>Example Requests</h1>
<p>Provide an Excel file of the minute data for the Hinds Farm station on
21 July 2024.</p>
<p><a class="reference external" href="https://mesonet.agron.iastate.edu/cgi-bin/request/isusm.py?station=AHDI4&amp;mode=hourly&amp;sts=2024-07-21T05:00Z&amp;ets=2024-07-22T05:00Z&amp;format=excel&amp;timeres=minute">https://mesonet.agron.iastate.edu/cgi-bin/request/isusm.py?station=AHDI4&amp;mode=hourly&amp;sts=2024-07-21T05:00Z&amp;ets=2024-07-22T05:00Z&amp;format=excel&amp;timeres=minute</a></p>
<p>Provide all of the daily data for the Hinds Farm station for the month of
July 2024 in a tab delimited format.</p>
<p><a class="reference external" href="https://mesonet.agron.iastate.edu/cgi-bin/request/isusm.py?station=AHDI4&amp;mode=daily&amp;sts=2024-07-01T00:00Z&amp;ets=2024-08-01T00:00Z&amp;format=tab">https://mesonet.agron.iastate.edu/cgi-bin/request/isusm.py?station=AHDI4&amp;mode=daily&amp;sts=2024-07-01T00:00Z&amp;ets=2024-08-01T00:00Z&amp;format=tab</a></p>
<p>Provide all of the hourly data for the Hinds Farm station for the month of
July 2024 in a comma delimited format with timestampts in UTC and include
any QC flags.  Also include the SoilVue 10 data.</p>
<p><a class="reference external" href="https://mesonet.agron.iastate.edu/cgi-bin/request/isusm.py?station=AHDI4&amp;mode=hourly&amp;sts=2024-07-01T00:00Z&amp;ets=2024-08-01T00:00Z&amp;format=comma&amp;tz=UTC&amp;qcflags=1&amp;vars=sv">https://mesonet.agron.iastate.edu/cgi-bin/request/isusm.py?station=AHDI4&amp;mode=hourly&amp;sts=2024-07-01T00:00Z&amp;ets=2024-08-01T00:00Z&amp;format=comma&amp;tz=UTC&amp;qcflags=1&amp;vars=sv</a></p>
<p>Same request, but compute the comprehensive climate index (CCI) with and
without shade effect and include those in the output as well.</p>
