Electronic Certificate of Real Estate Value (eCRV)

menu-blockmain

field_block:node:landing_page:body

An Electronic Certificate of Real Estate Value (eCRV) documents a property sale in Minnesota. The Department of Revenue and the county of sale review eCRV information to verify sale terms and to ensure fair property tax assessments.

An eCRV must be filed when Minnesota real property is sold or transferred for consideration of more than $3,000.

Learn more about getting involved in eCRV.

eCRV notifications, announcements, and application update information is provided through GovDelivery subscription. We encourage all eCRV users to subscribe to eCRV email updates.

New eCRV Links 
We recently updated our eCRV applications. As part of this update, all eCRV applications have new URLs. To access the updated version, use the links on this page. Find full details of the changes in the Technical Updates section under Release Notes.

For more information on user credentials, see the Roles section on the eCRV County and City Help page.

System Account Credentials for Web Services Applications

A System Account is for system programs where the ID and password are coded into a program written by the county, city, or vendor to run unattended integration with eCRV Web Services API. The password for these accounts will not expire and cannot be reset. One system account is created per county. The password and login ID are eight digits each.

With a Web Services account, you can only access Web Services API for the specific county, city, or vendor your account is for. You cannot access the eCRV user interface.

You must be the eCRV contact person at your county or city office to request system account credentials. To request credentials, send an email to ecrv.support@state.mn.us with:

  • First and last name
  • Phone number
  • County or city
  • Email address for the user being set up
  • If you are a vendor, your vendor name
  • Which account type you need, sandbox or production
 

Questions?

Sandbox for Testing and Training [+]

The sandbox is designed for property tax, local government, and vendors to use for testing and training purposes. The eCRV sandbox is a site to process test eCRVs. Test eCRVs do not represent real property sales, are ignored outside of testing purposes, and may be deleted due to system or database updates at any time.  

Testing Public Search and Submit

You can create and submit test eCRVs in the sandbox site without a login.

  • Test eCRV Submit - Create or edit a test eCRV  
  • Test Public Search - Find a test eCRV: only displays eCRVs that have been accepted by counties 

Testing County and City Applications

The IDs, the passwords and URL access are the not the same as the production regions. Separate URLs, logins and passwords are needed for both sandbox and production regions.

Monthly System Maintenance Windows

Trusted Exchange (log in) systems will perform system maintenance on Thursdays between 6 and 7 a.m. Trusted Exchange includes eCRV, Virtual Room, and Audit Room. Maintenance will only be performed when needed, and most updates will take less than 10 minutes. This is in addition to existing system updates that happen on the fourth Thursday and Friday of every month between 4 and 7 a.m. The eCRV system may be unavailable during these times.

​eCRV Weekly Sales Extract [+]

The eCRV Weekly Sales Extract includes property sales submitted and accepted through eCRV each week. Only eCRVs accepted by a county or city are included. The information is in XML format within a zipped folder. Each XML file represents a sale of property and only contains the information provided by the submitter; it does not contain any data that may be added by a county or city. 

Note: User-friendly eCRV information can be found by using the public search.

If the public search does not meet your needs, you can request access to the Weekly Sales Extract files by contacting ecrv.support@state.mn.us.
