Real Estate Historical Data

The Historical Data tool allows you to download a file containing all Wisconsin RETRs for the selected month and year. If you need RETR data that is older than 5 years, data from multiple months and/or years, or if you need to filter your data further by county, municipality, or other fields, please return to the previous screen and select the Search Wisconsin Property Data link and generate a report from there.
You have the option to generate your report as either a CSV or XML file. In most cases, a CSV file is easiest to read and understand since it formats as a table, but it is unable to show all grantors, grantees, and parcels if a return has multiple.
CSV (comma-separated values) File
  • Open with: Microsoft Excel, Google Sheets
  • Easiest to read
  • Displayed as a table where each row is one return
  • Can only show one grantor, one grantee, and one parcel
XML File
  • Open with: web browser (Microsoft Edge, Mozilla Firefox, Google Chrome)
  • Easiest to load into a program
  • Values are stored in tags
  • Can show all grantors, grantees, and parcels
