What this is not. It is not a headline aggregator. Republishing somebody else’s story is slower than the story, and adds nothing to it. Everything here is a change this site measured in a primary source it already polls, with the number in the item and a link to the page that shows the work.

What earns a place. Only a change the data itself defines: a bound the source file already carries (a 52-week high, a one-year positioning extreme, last week’s crop rating) or a plain percentage move. Nothing is measured against a threshold typed in by hand, because a number somebody invented is one that will eventually be wrong with no way to tell.
