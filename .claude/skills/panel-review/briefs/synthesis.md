# Synthesis brief template

Read the seat files and the skeptic file (<paths>). Drop anything the skeptic marked WRONG (list it under
"refuted"). Write for Sig: plain English, short sentences, verdict first, no em dashes.
1. The vision in one paragraph, as what a person sees in the first 30 seconds.
2. Where the board agrees (and why), where it disagrees (each side in one line).
3. Decisions only Sig can make, each with a recommendation and what it costs.
4. Bets ranked: cost, time to a yes or no answer, how we would know (the number we watch).
5. What we cannot know yet, and the data that would let us.
6. Refuted claims (one line each).
Under 1,200 words.
